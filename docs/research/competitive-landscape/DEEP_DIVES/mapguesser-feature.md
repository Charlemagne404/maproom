# MapGuesser — Find the Feature

**Reviewed:** 19 November 2026

## Public description

The [Find the Feature page](https://mapguesser.app/play/find-the-feature/) describes a five-round game for locating a named sea, gulf, bay, strait, lake, river or ocean on a world map. The player drops a pin, submits it and receives the target outline and a distance result. The page lists 616 features, including 188 rivers. Those counts and rules are the publisher's current public description.

## Direct play

One practice round was completed. The first prompt was “Tap the sea named Golfe du Lion.” After a pin was placed and submitted, the result showed “Missed it!”, zero points and a 1,627 km distance; the answer shape was highlighted on the map.

This was a sea round. River content was not directly tested, nor were settings beyond timer choices, a full five-round score, keyboard navigation or screen-reader output.

## Maproom relevance

This game already applies pin placement, feature outline reveal and distance feedback to physical geography. A Watershed Match concept that asks where a named river lies would repeat that action, and Riverways already asks players to name a highlighted river. A downstream relationship task could still be distinct if its answer is which outlet or mainstem receives the water, rather than a point on the map.
