# Geocore

**Sources:** [Classic catalog](https://www.geocore.fun/game-catalog), [Play](https://www.geocore.fun/play), [2.0 announcement](https://www.geocore.fun/blog/geocore-2-0) · **Accessed:** 19 November 2026.

## Observed

The current Classic catalog listed 85 modes, thirteen input styles and distinct counts for country, flag, state, shape, city and coordinate categories. Six items were tagged Windows-only. The same page labeled subsets “no-Pro” and “no-account.” The broader Play surface advertised 168 games and 2,200+ quizzes, while the 2.0 announcement reported 73 games at its October release; no current version label was visible.

A guest Click Country round displayed a 3D globe, a ten-question counter, answer status and a miss reveal. The wrong guesses Poland and Austria preceded the correct Switzerland reveal. The sampled guest view rendered a globe even though the catalog's setting labels distinguished flat-map access from a Pro 3D globe; the two surfaces may differ, so no entitlement conclusion is drawn from this single session. This one mode was not treated as representative of the Classic catalog.

## Interpretation and Maproom implication

The catalog's value lies in the number of distinct actions: type, click, identify, pin, estimate, rank, draw, reconstruct and recall. Mode-specific scoring, hints and tutorials appear more useful than a single universal map interaction. The count discrepancy is a reminder to identify the precise surface and version date before quoting totals. Maproom can borrow the principle of testing different skills, while keeping its smaller curated catalog coherent and avoiding input variants that only add settings without changing the challenge.

## Direct play: Geo Puzzle: Countries — 19 November 2026

The catalog describes this as “Drag every piece home and rebuild the map.” I started a guest World-countries round from the current Play surface without creating an account. Setup showed a 197-country world pool, automatic piece count, an empty board, normal snapping, no piece names, and no timer. The round contained 20 country pieces.

The main board presents an unlabeled world map and a horizontal tray of country shapes. A player can drag a piece or select it and tap the destination; zoom controls sit beside the map. The prompt uses the short “Rebuild The world” instruction. A hint identified Bulgaria as being in the northeast; one misplaced piece produced “over 5,000 km off.” A later Bulgaria placement snapped into the board in green and advanced the counter from 0/20 to 1/20 with 75 points. The one-piece observation does not establish whole-round pacing or scoring balance.

The browser accessibility tree exposed named piece controls and the board instruction “with the keyboard, the arrow keys move it and Enter drops it.” This session did not complete an arrow-moved placement, so keyboard completion is documented as an advertised/exposed control rather than a verified successful play. Other versions visible from setup included States & Regions and Build Outwards.

**Maproom decision.** The proposed Country Mosaic concept uses the same core action of rebuilding a world from country pieces. Defer that candidate unless a future version adds a distinct geographic learning goal and a keyboard/touch interaction that does not merely reproduce this round. This is a product-fit decision, not a judgment that Geocore's puzzle is poor.
