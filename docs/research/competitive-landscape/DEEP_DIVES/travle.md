# Travle

**Source:** [travle.earth](https://travle.earth/) · **Accessed:** 19 November 2026 · **Evidence:** one route decision played, help reviewed.

## Observed

A live puzzle showed Czech Republic to East Timor and invited the player to name countries along the shortest route. The UI displayed a remaining-guess count. Entering Poland produced a “Perfect guess” response and was accepted as an intermediate country; the action did not require the player to map-click a single exact path. Daily and practice/archive navigation were visible.

## Documented

The help describes route hints that reveal progressively more information about the next country: an outline, broader route outlines, and initials. It also documents qualitative route feedback (optimal, near-optimal or poor), behavior when a guessed country disconnects from the start, and selected bridge/tunnel connections.

## Interpretation and Maproom implication

The useful principle is to distinguish **whether a route works** from **how efficient it is**. Travle is a word-based path puzzle with shortest-route quality as an explicit target; Maproom Border Route uses a map and accepts intermediate countries in arbitrary entry order. Keep Maproom's flexibility and explain a valid longer path separately from shortest-path score. One played guess is not enough to assess overall difficulty, balance, or route-data edge cases.
